ABOUT THE PROJECT

From graph theory
to exam day.

A practical application of vertex coloring for conflict-free examination scheduling.

DMGT · GROUP EXPERIENTIAL LEARNING

Examination Timetable Scheduling using Vertex Coloring

This project models each subject as a vertex. An edge joins two subjects when at least one student is registered for both. A proper vertex coloring groups subjects into exam sessions without student conflicts.

Shared students→Conflict edge→Different exam slot

Implemented algorithms

Greedy Coloring

Visits vertices in the supplied order and assigns the first available color.

Welsh–Powell

Sorts vertices by descending degree, then applies a greedy coloring.

DSATUR

At each step colors an uncolored vertex with maximum neighbor color saturation.

ⓘ

All methods are heuristics. The app verifies that every edge has differently colored endpoints; this does not establish minimum coloring.

PROJECT SCOPE

What this app supports

  • Registration-based conflict graph construction
  • Manual registration and CSV upload
  • General graphs with 1–50 vertices and 0–50 edges
  • Three independently implemented coloring heuristics
  • Color class timetable generation and validation
  • Algorithm comparison with runtime statistics
